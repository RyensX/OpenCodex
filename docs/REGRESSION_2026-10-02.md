# 全流程回归记录（2026-10-02）

本次按用户要求检查现有完整测试套件、中继反向隧道和浏览器桥接链路，补充重连回归用例。自动化验证通过；真实官方 UI 和手机后台恢复验收仍受环境阻塞，不能据此认定全流程无 bug。

## 发现与修复

1. 浏览器离线时，官方 RPC 回包发送失败会销毁仍需恢复的 relay，可能使历史读取无法结束或旧 export 引用失效。现在有限保留离线回包，端口恢复后按 FIFO 投递；超限明确关闭会话。
2. 新 socket 的 hello/connect 先于旧 socket 的 close 时，旧 relay 尚未进入恢复索引，导致创建新的官方 RPC 会话。现在先登记旧连接的端口，再关闭旧 socket，并隔离旧 socket 的延迟清理。
3. 多端口整体迁移时，原逻辑只清当前端口的离线定时器，其他端口可能被过期任务关闭。现在清理所有迁移端口的定时器，各端口分别确认绑定后投递积压结果。
4. PWA 发现目录使用宿主平台的路径实现，跨平台调用 Linux/macOS 分支时产生错误路径。现在按目标平台使用 POSIX 路径。

另外修正过期的兼容点数量、默认模型努力档位、诊断页标题断言，以及 Windows 上的 POSIX 测试夹具。中继集成夹具同步当前设备 MAC、访问后缀和独立鉴权 Cookie 协议。未调整生产默认模型配置。
